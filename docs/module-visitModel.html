Module: visitModel

Módulo de modelos para la gestión de Visitas. Incluye funciones para buscar visitas activas por identificación o ID, buscar áreas, registrar nuevas visitas (entrada), y actualizar el registro al momento de la salida, todo manejando transacciones y logs.
