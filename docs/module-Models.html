Module: Models

Archivo de inicialización principal para Sequelize. Este módulo es responsable de: 1. Conectar a la base de datos con una lógica de reintentos. 2. Cargar dinámicamente todos los modelos de Sequelize definidos en el directorio. 3. Establecer las asociaciones (relaciones) entre los modelos. 4. Exportar el objeto `db` que contiene la instancia de Sequelize y todos los modelos cargados.
