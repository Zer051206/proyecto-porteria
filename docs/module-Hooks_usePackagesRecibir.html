Module: Hooks/usePackagesRecibir

Hook personalizado para gestionar la lógica del formulario de recepción de paquetes. Utiliza Formik para la gestión de formularios, Yup para la validación de esquemas, y realiza la carga inicial de datos (tipos de paquetes y áreas) y la sumisión del formulario.
